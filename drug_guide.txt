【第一類：高血壓與心血管用藥】

【藥物編號 01】
● 藥品名稱：脈優錠 5毫克 (Norvasc 5mg)[cite: 3, 4]
● 常用學名：Amlodipine Besylate[cite: 3, 4]
● 慢性病分類：高血壓 (鈣離子阻斷劑 CCB)[cite: 3, 4]
● 外觀特徵：白色八角形（八邊形）錠劑，中央有一字刻痕。[cite: 3, 4]
● 表面刻字標記：一面刻「AML 5」，另一面刻「VLE」。[cite: 3, 4]
● 主要適應症：高血壓、慢性心絞痛。[cite: 3, 4]
● 用法用量：每日一次，每次 1 錠 (5mg)，固定時間服用。[cite: 3, 4]
● 重要警語與注意事項：常見下肢水腫、頭痛、面部潮紅。避免併服葡萄柚（汁）以防血壓過低。[cite: 3, 4]

【藥物編號 02】
● 藥品名稱：易安穩膜衣錠 5/80毫克 (Exforge 5/80mg)[cite: 3, 4]
● 常用學名：Amlodipine + Valsartan[cite: 3, 4]
● 慢性病分類：高血壓 (複方 CCB + ARB)[cite: 3, 4]
● 外觀特徵：淡黃色或深黃色圓形雙凸膜衣錠，無刻痕。[cite: 3, 4]
● 表面刻字標記：一面印「NVR」，另一面印「NV」。[cite: 3, 4]
● 主要適應症：單方降血壓藥控制不佳之中重度高血壓。[cite: 3, 4]
● 用法用量：每日一次，每次 1 錠，固定時間服用。[cite: 3, 4]
● 重要警語與注意事項：孕婦絕對禁用。注意姿勢性低血壓與血鉀變化。[cite: 3, 4]

--------------------------------------------------------------------------------

【藥物編號 03】
● 藥品名稱：康肯膜衣錠 5毫克 (Concor 5mg)
● 常用學名：Bisoprolol Fumarate
● 慢性病分類：高血壓、心絞痛、慢性心衰竭 (乙型受體阻斷劑 Beta-blocker)
● 外觀特徵：淡黃色心形錠劑，帶有一字深刻痕。
● 表面刻字標記：無特殊文字，獨特的心形外觀為主要特徵。
● 主要適應症：高血壓、狹心症、穩定型慢性中度至重度心衰竭。
● 用法用量：每日早晨一次，每次 1 錠 (5mg)。
● 重要警語與注意事項：不可突然停藥以免反彈性心悸或血壓飆高；氣喘及嚴重慢阻肺患者慎用；服藥期間心跳過慢（小於每分鐘50下）應停藥就診。

【藥物編號 04】
● 藥品名稱：壓樂舒膜衣錠 40毫克 (Olmetec 40mg)
● 常用學名：Olmesartan Medoxomil
● 慢性病分類：高血壓 (血管張力素受體阻斷劑 ARB)
● 外觀特徵：白色圓形雙凸膜衣錠。
● 表面刻字標記：一面刻有「C15」，另一面平滑。
● 主要適應症：本態性高血壓。
● 用法用量：每日一次，每次 1 錠 (20~40mg)。
● 重要警語與注意事項：孕婦禁用；服用期間注意腎功能與血鉀數值，偶有輕微頭暈。

【第二類：高血糖與糖尿病用藥】

【藥物編號 05】
● 藥品名稱：庫魯化錠 500毫克 (Glucophage 500mg)[cite: 3, 4]
● 常用學名：Metformin HCl[cite: 3, 4]
● 慢性病分類：第二型糖尿病 (雙胍類 Biguanide / 第一線)[cite: 3, 4]
● 外觀特徵：白色長橢圓形錠劑，中間常帶切痕。[cite: 3, 4]
● 表面刻字標記：多數刻有「500」或廠牌縮寫代碼。[cite: 3, 4]
● 主要適應症：第二型糖尿病第一線用藥，改善胰島素敏感度。[cite: 3, 4]
● 用法用量：每日 2~3 次，隨餐或餐後立即服用以減輕胃腸道不適。[cite: 3, 4]
● 重要警語與注意事項：初期易引發腹瀉、腹脹。嚴重腎功能不全或洗腎者禁用；含碘顯影劑檢查前需暫停服用。[cite: 3, 4]

--------------------------------------------------------------------------------

【藥物編號 06】
● 藥品名稱：佳糖維膜衣錠 100毫克 (Januvia 100mg)[cite: 3, 4]
● 常用學名：Sitagliptin Phosphate[cite: 3, 4]
● 慢性病分類：第二型糖尿病 (DPP-4 抑制劑)[cite: 3, 4]
● 外觀特徵：米黃色、淺桃紅或橘色圓形雙凸膜衣錠。[cite: 3, 4]
● 表面刻字標記：一面刻有「277」，另一面平滑無字。[cite: 3, 4]
● 主要適應症：第二型糖尿病，促進腸泌素活性以調節胰島素。[cite: 3, 4]
● 用法用量：每日一次，每次 100mg，不受進食影響。[cite: 3, 4]
● 重要警語與注意事項：單獨使用不易發生低血糖；若出現持續性劇烈腹痛需提防罕見胰臟炎。[cite: 3, 4]

--------------------------------------------------------------------------------

【藥物編號 07】
● 藥品名稱：得瑪胰膜衣錠 2毫克 (Amaryl 2mg)
● 常用學名：Glimepiride
● 慢性病分類：第二型糖尿病 (磺醯尿素類 Sulfonylurea)
● 外觀特徵：綠色長橢圓形錠劑，兩面均有一字刻痕。
● 表面刻字標記：一面印有「NMK」，另一面印有廠牌標誌。
● 主要適應症：第二型糖尿病，刺激胰臟分泌胰島素。
● 用法用量：每日一次，於早餐或第一頓正餐前立即服用。
● 重要警語與注意事項：具有顯著的低血糖風險（可能出現手抖、冒冷汗、飢餓感），服藥後必須按時用餐；肝腎功能不全者慎用。

【藥物編號 08】
● 藥品名稱：排糖高膜衣錠 10毫克 (Jardiance 10mg)
● 常用學名：Empagliflozin
● 慢性病分類：第二型糖尿病、心衰竭 (SGLT2 抑制劑 / 排糖藥)
● 外觀特徵：淺黃色圓形雙凸膜衣錠。
● 表面刻字標記：一面印有勃林格殷格翰廠牌符號，另一面刻有「S10」。
● 主要適應症：第二型糖尿病（藉由尿液排出糖分）、降低心血管死亡與心衰竭住院風險。
● 用法用量：每日一次，每次 1 錠 (10~25mg)，早晨服用為宜。
● 重要警語與注意事項：服藥期間應補充足夠水分以防脫水；注意個人衛生，預防生殖泌尿道真菌感染。

【第三類：高血脂用藥】

【藥物編號 09】
● 藥品名稱：冠脂妥膜衣錠 10毫克 (Crestor 10mg)[cite: 3, 4]
● 常用學名：Rosuvastatin Calcium[cite: 3, 4]
● 慢性病分類：高血脂 (Statins 強效降膽固醇)[cite: 3, 4]
● 外觀特徵：粉紅色圓形雙凸膜衣錠。[cite: 3, 4]
● 表面刻字標記：一面刻「ZD4522」，另一面刻「10」（常見刻字標記 ZD4522 10）。[cite: 3, 4]
● 主要適應症：高膽固醇血症、混合型血脂異常、降低心血管事件風險。[cite: 3, 4]
● 用法用量：每日一次，每次 5~10mg，建議夜間睡前固定服用。[cite: 3, 4]
● 重要警語與注意事項：若出現不明原因肌肉痠痛、無力或深色茶色尿液，應立即就醫排查橫紋肌溶解症。[cite: 3, 4]

【藥物編號 10】
● 藥品名稱：立普妥膜衣錠 10/20毫克 (Lipitor 10/20mg)[cite: 4, 7, 8]
● 常用學名：Atorvastatin Calcium[cite: 3, 4]
● 慢性病分類：高血脂 (Statins 長效降膽固醇)[cite: 3, 4]
● 外觀特徵：白色圓形或橢圓形膜衣錠。[cite: 3, 4, 7, 8]
● 表面刻字標記：一面刻「ATV」，另一面刻劑量「10」或「20」（如 ATV 10、ATV 20）。[cite: 3, 4, 7, 8]
● 主要適應症：降低 LDL-C 及三酸甘油酯，預防心肌梗塞。[cite: 3, 4]
● 用法用量：每日一次，整天任何固定時間服用皆可。[cite: 3, 4]
● 重要警語與注意事項：需定期追蹤肝功能指數 (ALT/AST)；避免過量飲用葡萄柚汁。[cite: 3, 4]

【第四類：心血管抗血栓用藥】

【藥物編號 11】
● 藥品名稱：伯基腸溶微粒膠囊 100毫克 (Bokey 100mg)[cite: 3, 4]
● 常用學名：Aspirin 腸溶微粒[cite: 3, 4]
● 慢性病分類：心血管預防 (抗血小板凝集)[cite: 3, 4]
● 外觀特徵：鮮橘色／透明雙色長圓柱膠囊，內含白色顆粒。[cite: 3, 4]
● 表面刻字標記：膠囊外殼印有「YSP」與「BKCP」黑色字樣。[cite: 3, 4]
● 主要適應症：預防心肌梗塞、血栓栓塞與缺血性腦中風。[cite: 3, 4]
● 用法用量：每日一次，每次 1 粒。腸溶劑型請配水整粒吞服，切勿咬碎。[cite: 3, 4]
● 重要警語與注意事項：具胃腸出血風險；拔牙或手術前 5~7 天須告知醫師評估停藥時機；留意黑便或不明瘀青。[cite: 3, 4]

● 常用學名：Clopidogrel Bisulfate[cite: 3, 4]
● 慢性病分類：心血管預防 (ADP 受體拮抗劑 / 抗血小板)[cite: 3, 4]

● 重要警語與注意事項：不可擅自停藥以免引發急性支架血栓；若出現咳血、血尿須儘速就診。[cite: 3, 4]

【第五類：其他常見高齡慢性病用藥（痛風、甲狀腺、攝護腺）】

【藥物編號 13】
● 藥品名稱：福避痛膜衣錠 80毫克 (Feburic 80mg)
● 常用學名：Febuxostat
● 慢性病分類：高尿酸血症、痛風 (黃嘌呤氧化酶抑制劑)
● 外觀特徵：淡黃色長橢圓形雙凸膜衣錠。
● 表面刻字標記：一面刻有「80」，另一面平滑。
● 主要適應症：慢性痛風患者的高尿酸血症。
● 用法用量：每日一次，每次半顆至一顆 (40~80mg)，不受進食影響。
● 重要警語與注意事項：不可在痛風急性發作期開始服藥（易延長發作）；用藥初期可能引發痛風短暫反彈發作，宜多喝水。

【藥物編號 14】
● 藥品名稱：昂特欣錠 100微克 (Eltroxin 100mcg)
● 常用學名：Levothyroxine Sodium
● 慢性病分類：甲狀腺機能低下 (甲狀腺素補充)
● 外觀特徵：白色圓形錠劑，一面有一字深刻痕。
● 表面刻字標記：一面刻有「100」，另一面為刻痕。
● 主要適應症：甲狀腺機能減退症、黏液水腫。
● 用法用量：每日早晨一次，空腹時以白開水服用（服藥後半小時至一小時才可進食早餐）。
● 重要警語與注意事項：鐵劑、鈣片或胃藥會嚴重干擾吸收，需間隔至少 4 小時服用；不可隨意調整劑量以免心悸或手抖。

【藥物編號 15】

● 常用學名：Tamsulosin HCl
● 慢性病分類：良性攝護腺肥大 (甲型交感神經阻斷劑 Alpha-1 blocker)
